## Novidades

- **Seletor de estilos em cartões.** Cada estilo mostra o desenho do mesmo aparador, o nome e uma dica, agrupados por família. A busca acha pelo nome e pelas palavras da pessoa ("nórdico" acha o escandinavo). Funciona no painel do projeto e na biblioteca de móveis.
- **Busca sem caixa dupla.** As buscas do seletor de estilos e da biblioteca não desenham mais uma segunda caixa dentro do campo ao receber o foco.
- **Deploy automático.** Cada push no `main` roda os testes e publica na Cloudflare pelo GitHub Actions. O selo no README e a lateral do repositório mostram o resultado.
- **Releases automáticas.** Subir a versão no `package.json` cria a release no deploy, com as notas de `docs/releases/`.
- **README novo**, com os doze estilos, as peças, as mesas e a biblioteca de 30 móveis.
